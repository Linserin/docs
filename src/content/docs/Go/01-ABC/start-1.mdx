## Hello World!

```powershell
go mod init example/hello
```

<Aside title="go.mod" type="info">
  此时在工作目录下方应该会存在一个 `go.mod` 文件，此文件为 Go 项目的标志，随后 `go mod tidy` 会用到。
</Aside>

粘贴代码：

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}
```

运行：

```shellscript
>go run .
Hello, World!
```

## 构建输出：
