## 字符串操作
### 判断字符串是否以特定前缀开头
```go
if strings.HasPrefix(str, "Start With..."){fmt.Println("Yes!")}
```
### 判断字符串是否以特定前缀结尾
```go
if strings.HasSuffix(str, "Start With..."){fmt.Println("Yes!")}
```
### 判断包含
```go
if strings.Contains(str, "Contains..."){fmt.Println("Yes!")}
```
<Aside type="Info" title="提示">
如果 *需要寻找的内容* 为空字符串，那么一定返回 `true`.

如果 `str` 为空字符串，返回 `false`.
```go
strings.HasPrefix("", "")      // true
strings.HasPrefix("", "a")     // false

strings.HasSuffix("", "")      // true
strings.HasSuffix("", "a")     // false

strings.Contains("", "")       // true
strings.Contains("", "a")      // false
```
此处均区分大小写，如果需要不区分，可以先将其全部转为小写。

```go
lowerStr := strings.ToLower(str)
```
</Aside>

## 读取文件
### 逐行阅读

```go
package main

import (
	"bufio"
	"fmt"
	"os"
)

func main() {
	file, err := os.Open("file.txt")
	if err != nil {
		fmt.Println(err)
		file.Close()
		os.Exit(1)
	}
	sc := bufio.NewScanner(file)
	sc.Buffer(make([]byte, 64*1024), 1024*1024) // 可选： 限制行大小
	var line int
	for sc.Scan() {
		line++
		content := sc.Text()
		fmt.Println(line, ": ", content)
	}
	if sc.Err() != nil {
		fmt.Println(sc.Err())
		file.Close()
		os.Exit(1)
	}

}

```
