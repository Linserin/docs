# Linserin Yang's Notes
This is the source code of [Linserin Yang's Notes](https://notes.linserin.work/) which is built by [Astro](https://astro.build) and [nimbus-docs](https://nimbus-docs.com/)
## Start a Develop Server
```
pnpm install
pnpm dev
```
## Self-host
```
pnpm install
astro build
```
Its build artifacts should be output in the `dists` folder.
## How to use components
See the [guide](https://notes.linserin.work/%E5%8F%82%E8%80%83%E8%B5%84%E6%96%99/components/) in the docs.
