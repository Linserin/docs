## 介绍
tmux（Terminal Multiplexer）是一个终端复用工具，它允许你在单个终端窗口中创建多个虚拟终端会话，并能保持这些会话在后台运行。与直接使用终端相比，tmux 提供了更强大的会话管理功能。

把 tmux 理解成浏览器，单个浏览器 **窗口**  对应 tmux 的会话; 相应地，一个浏览器窗口可以开启多个 **标签页**; 每个 tmux 标签页可以分割为不同的 **面板**。
## 一览
### 命令一览
| 命令 | 效果 |
| --- | --- |
| `tmux` | 开启新的 tmux 会话 |
| `tmux at` | 连接上一个会话 |
| `tmux at -t n` | 连接编号为 `n` 的会话 |
| `tmux ls` | 列出会话 |
| `tmux sp` | 上下切分当前标签页（需要在 tmux 窗口内执行） |


### 快捷键一览
通常，需要按下 `Ctrl + B` 来表示接下来的按键是发送到 tmux。

| **按键** | **效果** |
| --- | --- |
| **会话** |
| `Ctrl+b d` | 断开会话连接（将会在后台保持）|
| `Ctrl+b $` | 重命名当前会话 |
| `Ctrl+b s` | 切换会话 |
| **标签页** |
| `Ctrl+b c` | 创建新标签页 |
| `Ctrl+b &` | 关闭当前标签页 |
| `Ctrl+b p/n` | 向前 / 向后切换标签页 |
| `Cirl+b n` | 切换到指定编号标签页 |
| `Ctrl+b ,` | 重命名标签页 |
| **面板** |
| `Ctrl+b %` | 垂直分割当前面板 |
| `Ctrl+b "` | 水平分割当前面板 |
| `Ctrl+b <arrow>` | 在面板间移动焦点 |
| `Ctrl+b x` | 关闭当前面板 |
| `Ctrl+b z` | 最大化/恢复当前面板 |
| `Ctrl+b Space` | 切换面板布局 |
